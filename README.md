# Neo parser 1.1 (Neon)

Парсер Яндекс Карт для поиска клиентов: сбор организаций, контакты, Excel-базы.
Собственная реализация (оригинальный код), функционально повторяет бесплатный набор «Базы + парсер Яндекс Карт».

## Новое в фильтрах
1. **Без сайта** — только компании без собственного сайта (соцсети, Яндекс, агрегаторы сайтом не считаются).
2. **ВК / Telegram / WhatsApp — отдельно.** Чекбоксы (режим «любой из выбранных» / «все выбранные») и отдельные вкладки
   «Все · Без сайта · ВКонтакте · Telegram · WhatsApp» со счётчиками. «Скачать XLSX» выгружает текущую вкладку с фильтрами.
3. Дополнительно: «Без мессенджеров (для обзвона)», «Есть телефон», «Есть email», минимальный рейтинг.

## Сборка EXE через GitHub (без установки Python у вас)
1. Создайте репозиторий на GitHub и загрузите в него **содержимое папки `neo`** (чтобы `app.py` лежал в корне, а `.github/workflows/build.yml` — по пути `.github/workflows`).
2. Вкладка **Actions** → workflow **Build Neo parser (Windows)** → **Run workflow** (или просто сделайте push).
3. После успешной сборки откройте **Artifacts** → `Neo_parser_win64` и скачайте ZIP.
4. Распакуйте ZIP целиком и запустите `Start Neo parser.bat` или `Neo parser.exe`.
5. При первой проверке браузера программа скачает Chromium в папку `browsers` рядом с EXE. Это нужно сделать один раз; далее браузер используется локально.

**Почему ZIP меньше:** Chromium не включается в архив. Это убирает сотни мегабайт браузерных файлов и не дублирует обычный Chromium с отдельным Headless Shell. Для первой установки Chromium нужен интернет. Сам EXE проходит smoke-test в GitHub Actions до публикации.
Релиз по тегу: `git tag v1.1.0 && git push --tags` — ZIP прикрепится к Releases.

## Запуск из исходников
**Windows:** установите Python 3.10+ (галочка Add to PATH), дважды щёлкните `Neo parser.bat`.
Первый запуск сам поставит зависимости. При первой проверке браузера Chromium загрузится автоматически (нужен интернет). Откроется http://127.0.0.1:5057.
**Linux/macOS:** `./run.sh`.  Ручной запуск: `pip install -r requirements.txt && python -m playwright install chromium --no-shell && python app.py`.

## Работа
Город (подсказки по 1 116 городам, кнопки миллионников) + рубрики (несколько через запятую) → «Начать сбор».
Капча: пройдите в окне браузера (фоновый режим должен быть выключен). Базы сохраняются в `databases/` автоматически,
в том числе при остановке или ошибке. Раздел «Базы» открывает старые XLSX в таблице.

## Разделы
Базы данных (статистика, действия с файлами) · Яндекс Карты (лимит на каждую пару город/рубрика, проверка браузера) ·
Макеты сайтов (шаблонные HTML без нейросети + ZIP) · Рассылка (ручная: ссылки на чаты, текст в буфер, отметки «отправлено») ·
AI-ассистент (DeepSeek/Gemini) · Настройки · Инструкция с поиском · Журнал внизу окна (открыть / очистить / файл `logs/neo.log`).

## Структура
`app.py` сервер · `core/yandex.py` парсер · `core/contacts.py` разбор контактов · `core/filters.py` фильтры ·
`core/deep.py` поиск контактов на сайтах · `core/export.py` XLSX · `static/index.html` интерфейс · `tests/` тесты (`python tests/run.py`).

## Важно
- Селекторы Яндекс Карт меняются; парсер использует запасные варианты, но при изменении вёрстки их придётся обновить в `core/yandex.py`.
- Тесты проверяют конвейер на локальном макете страниц, а не на живом Яндексе.
- Используйте данные в рамках законодательства (152-ФЗ, закон о рекламе) и условий сервисов.
- Справочник городов: hflabs/city, CC BY-SA 4.0 (`assets/cities-data-license.txt`).
