# Neo Parser 2.0

Desktop-приложение для поиска и квалификации компаний, которым потенциально нужен сайт.

**CEO Neki · Lead Intelligence**

## Возможности

- Автоматический поиск организаций через **официальный API 2ГИС** (Catalog / Places)
- Выбор города (Москва, МО, Санкт-Петербург, ЛО) и ниши / произвольного запроса
- Сохранение лидов в локальную SQLite-базу с дедупликацией
- Аудит сайтов: доступность, HTTPS, формы, портфолио, каталог, мобильность
- Объяснимый **Lead Score** 0–100 с причинами и уверенностью
- Экспорт CSV / XLSX
- Тёмный SaaS-интерфейс на PySide6 (Dashboard, Search, Leads, Audit, Categories, History, Settings)
- Фоновые workers — UI не зависает; поиск и аудит можно остановить

## Требования

- Python 3.12+
- API-ключ 2ГИС с доступом к Catalog / Places API  
  Получение: [platform.2gis.ru](https://platform.2gis.ru) / [dev.2gis.ru](https://dev.2gis.ru)

Без ключа поиск **не выполняется** и **не имитируется**. Остальной функционал (импорт CSV, аудит, экспорт, CRM) работает.

## Установка и запуск

```bash
cd NeoParser
python -m venv .venv

# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
cp .env.example .env   # опционально: пропишите TWOGIS_API_KEY=

python main.py
```

Скрипты:

- Windows: `scripts/run_windows.bat`
- macOS: `scripts/run_macos.sh` (chmod +x)

Ключ также можно вставить в разделе **Settings** — он сохраняется в `~/.neo_parser/settings.json`.

## Сборка

```bash
pip install pyinstaller
# Windows
pyinstaller pyinstaller_windows.spec
# macOS (Apple Silicon)
pyinstaller pyinstaller_macos.spec
```

Артефакты появятся в `dist/`. Подписи/нотаризации нет — при первом запуске ОС может показать предупреждение.

## Тесты

```bash
pytest tests/ -q
```

Тесты не требуют API-ключа и сети.

## Важно

- Соблюдайте условия использования 2ГИС API, лимиты и политику данных.
- Приложение не обходит CAPTCHA и не парсит закрытые интерфейсы.
- Секреты не коммитьте: `.env` и `settings.json` в `.gitignore`.

## Что требует API-ключа

- Автопоиск на вкладке **Search** (2ГИС `/3.0/items`).

## Что работает без ключа

- Импорт CSV, таблица лидов, статусы CRM, аудит сайтов, Lead Score, экспорт, история, категории.


## Обновления технической основы

- Chromium для Playwright устанавливается при первом запуске в постоянную папку
  `~/.neo_parser/playwright-browsers` (Windows: профиль пользователя, `.neo_parser`).
  Браузер не должен искаться внутри временной папки PyInstaller `_MEI...`.
- При ошибке загрузки страницы 2ГИС выполняются до трёх попыток, после чего
  обработка продолжается со следующей страницей.
- Добавлено извлечение и хранение публичного контакта WhatsApp.
- По умолчанию поиск отбрасывает карточки без публичного способа связи
  (телефон, email, сайт, VK, Telegram или WhatsApp).
- Повторное обнаружение обновляет контактные и аудиторские данные, но сохраняет
  CRM-статус и заметки.
- Создаётся ежедневная резервная копия SQLite; хранятся последние семь копий.
- Сайт каждой найденной компании проверяется до расчёта итоговой оценки.
- Для PyInstaller включаются ресурсы Playwright (`--collect-all playwright`).

Примечание: автоматическая загрузка Chromium требует подключения к интернету при
первом запуске. Бесплатный поиск через публичный сайт 2ГИС зависит от доступности
самого сайта и его ограничений; это не является гарантией доступа ко всем данным
или всем регионам.

## Интерфейс Neo Parser 2.1

- Обновлённая тёмная визуальная система: графитовые поверхности, мягкие градиенты,
  аккуратные бирюзовые/синие неоновые акценты и более заметная иерархия элементов.
- На главной странице добавлены KPI-карточки, сводная визуализация базы и прогресс аудита.
- Добавлены плавные переходы между разделами; анимации можно отключить в настройках.
- Добавлено переключение русского/английского языка без перезапуска приложения.
- Язык и настройка анимаций сохраняются в локальном `~/.neo_parser/settings.json`.
- Поиск, SQLite, CRM и существующие данные остаются на прежних сервисах и не требуют миграции.
